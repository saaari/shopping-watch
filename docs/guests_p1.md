# P1 손님 5종 — 여정 카드

> GDD §7 "콘텐츠 파이프라인 검증"의 산출물. 카드 5장이 쉽게 써지면
> 아키타입×노선×계절 조합 파이프라인 성립, 저항하면 구조 과잉의 조기 경보.
> 슬롯: 정체 / 노선 / 목적지 / 미끼 취향(메뉴 반응) / 전수 레시피 / 엽서 문구.

---

## 1. 소소 (통근 정령) — 완행 · 단골 후보

- **정체**: 매일 아침 같은 시간, 완행 첫차로 지나가는 작은 정령. 어디로
  출근하는지는 아무도 모른다(본인도 잘 모르는 눈치).
- **노선**: 완행 (잉걸불부터 항상 온다 — 플레이어의 첫 손님이자 첫 단골 후보,
  Day 4~7 단골 등극 배치)
- **목적지**: 없음 — 왕복이 여정인 손님. 대신 단골 서사가 "출근길의 작은 변화"
  로 진행된다 (부탁 체인: "내일은 좀 든든한 걸로 부탁해요. 큰 날이거든요.")
- **미끼 취향**: 아침 메뉴(간단한 것). 국밥류가 걸리면 "아침부터 이건 좀…"
  하면서도 먹는다.
- **전수 레시피**: 『서서 먹는 주먹밥』 — 첫 단골 등극 보상. (재료: 무맥락
  곡물류 — 폰 연동 전 플레이어도 만들 수 있는 입문 레시피)
- **엽서 문구**: 엽서 없음 — 대신 **쪽지**: "오늘도 잘 먹었어요. 내일 또 올게요."
  (매일 오는 손님의 엽서는 쪽지다)

## 2. 잿불이 (화로 도깨비) — 잉걸불 손님

- **정체**: 불 꺼진 화로에서 태어난 늙은 도깨비. 시끄러운 날엔 오지 않고,
  역이 조용한 날에만 잉걸불 곁에 와서 앉는다. 말수가 적다.
- **노선**: 노선 없음 — **잉걸불 손님** (첫만남: 자연 잉걸불 날 또는 정기
  휴업일. 이후 화력 무관하게 대합실에 가끔 머묾). 업적 『불가에 앉은 손』 대상.
- **목적지**: 없음 — 머무는 존재. 목적지 슬롯 대신 **머무는 이유**: "불은
  꺼질 때 가장 따뜻한 냄새가 나거든." (잉걸불 서사의 화신 — 낮은 불이 결핍이
  아니라 다른 계절임을 대사로 증명하는 역할)
- **미끼 취향**: 메뉴 무관 — 늘 "오늘 남은 것"을 주문한다. (재고 소진 메커닉과
  연결, 완판 방지 밸브)
- **전수 레시피**: 『잉걸불 군고구마』 — 잉걸불 상태에서만 조리 가능한 유일
  레시피 (낮은 불의 전용 콘텐츠, "잉걸불이라 못 만드는 것"이 아니라 "잉걸불이라
  만들 수 있는 것")
- **엽서 문구**: 없음 — 대신 겨울 첫 잉걸불 날, 화로 앞자리에 **말없이 놓인
  군밤 한 봉지** (텍스트 없는 보상 — 말수 적은 캐릭터의 정합)

## 3. 남풍 (제비 우체부) — 급행 · 계절 단골

- **정체**: 계절 우편을 나르는 제비 정령. 봄엔 북상 편, 가을엔 남하 편을 탄다 —
  **게임의 모든 엽서를 배달하는 존재**이기도 하다 (엽서 시스템의 서사적 얼굴).
- **노선**: 급행 (봄·가을에만 정차하는 계절 노선 — 계절 단골의 원형. 실제 달력
  봄가을마다 돌아와 지난 만남을 기억한다)
- **목적지**: 봄엔 북쪽 나라, 가을엔 남쪽 나라 (매번 반대 방향 — 배웅이 연 2회
  리듬을 만든다)
- **미끼 취향**: 가볍고 빨리 나오는 것 (배달 중이라 급하다). 볶음류.
- **전수 레시피**: 『바람 태운 볶음국수』 — 가을 배웅 보상. (재료: 빠른 걸음
  태그 — "급한 요리엔 급한 걸음")
- **엽서 문구**: "남쪽에 무사히 도착. 다른 새들 편지만 나르다가 내 것을 쓰는 건
  처음이야. 봄에 봐." (우체부가 처음으로 자기 엽서를 쓴다 — 배웅 시스템의
  정서적 페이오프)

## 4. 눈여우 상인 — 특급 · 희귀

- **정체**: 먼 북쪽 나라의 행상. 등짐에 뭐가 들었는지 아무도 못 봤다.
  센불 특급이 서는 날에만 나타난다.
- **노선**: 특급 (센불 전용 — "꾸준히 걸은 주"의 상징 보상. 초대장의 단골
  주인공: "내일 아침까지 걸으면 특급이 서고, 소문의 눈여우 상인이 온대요")
- **목적지**: 다음 장이 서는 곳 (구체 지명 없음 — 상인은 늘 "다음 장"으로 간다.
  재방문 명분이 설정에 내장)
- **미끼 취향**: 국물 (북쪽 출신이라 뜨끈한 것에 약하다). 국물 메뉴가 걸린 날
  체류가 길어진다 → 전수 확률 상승 (메뉴=미끼와 전수의 연결 고리 예시).
- **전수 레시피**: 『북국 눈밑 만두』 — 눈 태그 재료 필요 (겨울 한정 + 센불
  손님의 조합 = 이 게임 장기 목표의 표본. 헌법 4에 따라 못 만나도 내년 겨울에
  다시 온다)
- **엽서 문구**: "장은 망했어. 하지만 국물 생각에 다시 가는 중이야. 만두는
  연습해 뒀나?" (엽서가 다음 방문 예고를 겸한다 — 전방 예고, 반사실 없음)

## 5. 우산 정령 — 유령 노선 · 푸른불

- **정체**: 잃어버린 우산들이 모여 태어난 정령. 비 오는 날 주인 잃은 우산을
  주우러 다닌다. 젖은 여행자를 보면 그냥 못 지나친다.
- **노선**: 유령 노선 (푸른불 플레어 — **비 태그 맥락 재료를 획득한 날만**
  정차. "새벽 빗길을 걸은 날, 새벽 빗길의 손님이 온다"의 표본)
- **목적지**: 비가 오는 다음 동네 (기상 연동 설정 — 어디에나 비는 오므로
  재방문 무한 명분)
- **미끼 취향**: 국물 전용. 국물 메뉴가 없으면 차만 마시고 간다 (그래도 팁은
  놓고 간다 — 무벌).
- **전수 레시피**: 『화요일의 빗물국』 — 기억 각인 재료(비 태그) 전용. 끓일 때
  빗소리가 난다 (P3 사운드 시그니처 표본. GDD 일지 예문 "우산 정령에게 『화요일의
  빗물국』을 냈다"의 출처)
- **엽서 문구**: "옆 동네도 비. 우산 셋을 주인에게 돌려줬어. 그 국은 비 오는
  날에만 끓여 줘 — 맑은 날 먹으면 맛이 심심하니까." (레시피 사용 조건을
  세계관이 설명)

## 파이프라인 검증 결과

**판정: 성립 — 단, 카드 템플릿에 변형 규칙 1개 필요.**

- 5장 작성에 구조적 저항 없음. 노선이 정해지면 정체→취향→레시피가 연쇄적으로
  따라 나온다 (노선 = 콘텐츠 생성의 시드로 작동함을 확인).
- **발견된 마찰 1**: "목적지/엽서" 슬롯은 **여행자 전용**이다. 머무는 손님
  (소소·잿불이)에게 강제하면 부자연 → 변형 규칙: 매일 오는 손님은 목적지 대신
  **왕복 서사 + 쪽지**, 잉걸불 손님은 **머무는 이유 + 무언의 선물**. 카드
  템플릿은 "여행형/왕복형/체류형" 3변형으로 확정.
- **발견된 이득 1**: 각 카드가 시스템 1개씩의 표본을 겸하게 됐다 (소소=단골
  체인, 잿불이=잉걸불 전용 콘텐츠, 남풍=계절 회귀+엽서, 눈여우=초대장+계절
  한정, 우산=플레어+기억 각인). P1 테스트에서 시스템별 정서 반응을 손님별로
  관측 가능.
- 확장 산수: 카드 1장 = 슬롯 6개 × 한두 문장. 절기당 손님 1(연 24장)은 이
  속도면 1인 예산에 충분히 든다.
