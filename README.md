# Walk n Wok

> **퇴근길이 장보기가 된다.**
> 당신이 실제로 사는 하루가, 바탕화면 속 작은 식당의 재료가 된다.

코지 판타지 식당 아이들러. 한글 가칭 **소소식당** — 정식 타이틀은 미확정.

- **플랫폼**: Steam (데스크탑 메인) + 모바일 동반 앱 (재료 수집기)
- **엔진**: Godot 4.x
- **상태**: 기획 확정 (사이클 v0.2) — 프로토타입 P1 준비 중
- **두 가지 플레이 모드**: 일하는 동안 곁눈질하는 살아있는 창(곁눈질 모드),
  또는 저녁 30분의 개점 리추얼(체크인 모드) — 둘 다 완결된 경험
