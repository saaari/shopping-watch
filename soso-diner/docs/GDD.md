## 한 줄 컨셉

**"당신이 실제로 사는 하루가, 바탕화면 속 작은 식당의 재료가 된다."**

책상 앞에 앉아 일하는 동안 모니터 속 식당도 함께 일하고,
밖에 나가 걷는 시간은 장을 보러 가는 시간이 되는 — 잔잔한 판타지 식당 아이들러.

## 핵심 정체성

| 항목 | 내용 |
|---|---|
| 장르 | 코지(cozy) 아이들러 + 데이터 연동 수집/제작 |
| 플랫폼 | **Steam (데스크탑, 메인)** + 모바일 동반 앱 (재료 수집기) |
| 엔진 | Godot (데스크탑) / 모바일 앱은 추후 결정 |
| 타깃 | 직장인·학생. 컴퓨터 앞에 오래 앉아 있고, 잔잔한 게임을 곁에 두고 싶은 사람 |
| 세일즈 훅 | "일하는 동안 바탕화면에서 살아있는 식당" + "내 삶이 게임의 재료" |
| 톤 | 따뜻함, 잔잔함, 약간의 판타지. 죄책감 없음 |

## 왜 이 조합인가 (디자인 논리)

1. **아이들러의 약점 보완** — 보통 아이들러는 결국 숫자놀음이 되지만,
   여기선 자원의 출처가 "내 실제 삶"이라 모든 재료에 서사가 있다.
2. **두 기기 = 두 가지 삶의 모드** — 폰만으로도, 데스크탑만으로도 완성되지 않는다.
   - 앉아 있는 시간(데스크탑) = 식당의 영업시간
   - 움직이는 시간(폰) = 장 보러 가는 시간
3. **시장 포지셔닝** — 모바일은 걸음수 게임 레드오션 + F2P 지옥.
   Steam은 코지 게임 팬덤이 두텁고 유료 인디가 팔린다.
   "일하는 동안 곁에 두는 식당"은 Steam 위시리스트 문구로 유효.

## 코어 루프

### 하루 단위 루프

```
아침  데스크탑 켬 → 식당 개점. 어제 산책으로 구한 재료가 배달되어 있음
낮    나는 일/과제, 식당은 영업 (방치). 쉬는 시간에 흘끗 → 클릭 몇 번 (개입)
저녁  폰 들고 퇴근/하교 → 걷는 만큼 장보기. 날씨·시간·장소가 재료의 "질감"이 됨
밤    식당 마감. 단골이 남긴 쪽지. 내일의 메뉴를 걸어두고 잠듦
```

### 분 단위 루프 (데스크탑 영업 중)

```
재료 입고 → (자동) 손질 → (자동) 조리 → 손님 서빙 → 돈 획득
                ↑ 클릭으로 가속 가능 (설거지, 재료 손질, 서빙 돕기)
돈 → 주방 도구(자동화 속도) / 식당 확장·가구 / 새 레시피
```

### 동기부여 루프 (이 게임의 심장)

```
게임에서 희귀 레시피 발견 → 필요한 재료 확인 →
"『비 오는 밤의 3,000보』가 필요하네?" →
현실에서 그런 하루를 살아보고 싶어짐 → 걷는다 → 재료 획득 → 요리 → 다음 목표
```

**게임이 현실의 나를 움직이게 만드는 순간이 이 게임의 존재 이유다.**

## 시스템 설계

### 1. 재료 시스템 — "상황이 새겨진 재료"

폰이 하루의 활동을 **맥락이 붙은 재료**로 증류한다.
같은 걸음도 상황이 다르면 다른 재료가 된다.

| 데이터 축 | 예시 |
|---|---|
| 걸음 수 (양) | 재료의 기본량. 1,000보 단위로 재료 1개 등 |
| 날씨 | 『빗속의 귀갓길』(국물 계열), 『쾌청한 아침 산책』(샐러드 계열) |
| 시간대 | 『자정의 산책』(야식 계열), 『새벽 러닝』(매콤한 볶음 계열) |
| 심박/강도 (선택) | 『폭주하는 심장』 — 희귀 향신료 계열. 웨어러블 있으면 보너스 |
| 장소 다양성 (GPS, 선택) | 새 동네 = 새 특산 재료. 프라이버시 고려해 좌표가 아닌 "새로움" 정도만 사용 |

- 재료는 **도감**에 수집된다. 희귀 조합(보름달 + 심박 급상승 + 새벽 등)은 전설 재료.
- 프로토 1단계에서는 실제 데이터 대신 **목업 입력(슬라이더/버튼)** 으로 검증.

### 2. 식당 운영 — "두 속도의 주방 (Two-Speed Kitchen)"

**🐢 방치 (기본값)** — 식당은 자동으로 굴러간다. 느리지만 확실하게.
주방을 돕는 존재(정령/견습생, 미정)가 손질·조리·서빙을 담당.

**⚡ 개입 (보너스)** — 쉬는 시간에 흘끗 보고 클릭 몇 번.
- 설거지: 쌓인 그릇 클릭 → 테이블 회전율 상승
- 재료 손질: 클릭 → 다음 요리 가속
- 서빙 돕기: 클릭 → 팁 보너스
- 각 인터랙션은 **5~30초 사이즈**. "잠깐 딴짓" 규격.

**철칙: 클릭하지 않아도 절대 벌하지 않는다.**
손님이 화내며 나가지 않고, 식당이 망하지 않는다.
방치는 기본값, 개입은 보너스. 이 게임은 "일하는 나를 응원하는 동료"다.

### 3. 경제 (돈의 사용처 = 성장의 세 축)

| 사용처 | 성장 축 | 효과 |
|---|---|---|
| 🍳 주방 도구 업그레이드 | 아이들러 성장 | 방치 속도·효율 상승 (자동화) |
| 🪑 식당 확장·가구·인테리어 | 꾸미기 | 손님 수, 분위기, 스크린샷 욕구 |
| 📜 새 레시피 | 수집 | 새 재료의 사용처, 도감, 스토리 해금 |

### 4. 손님과 스토리 — "잔잔한 판타지"

- 손님은 정체가 다양한 판타지 존재들 (지나가는 정령, 피곤한 도깨비, 미정).
- **단골 시스템**: 특정 요리를 반복 제공하면 단골이 되고, 사연이 조금씩 열린다.
- 손님의 부탁: "요즘 쓸쓸한 맛이 먹고 싶어요" → 그런 재료가 나오는 하루를 살아서 구해온다.
- 스토리는 짧은 쪽지·대사 단위. 텍스트 부담 최소, 여운 위주.

### 5. 모바일 동반 앱 (2단계)

- 역할: 걸음·(선택)위치 다양성·(선택)심박 수집 → 재료로 증류 → 서버에 저축
- 데스크탑을 켜면 "재료 배달" 수령. **돌아왔더니 쌓여 있는 보상**이 핵심 쾌감.
- 앱 자체는 게임이 아니라 가벼운 수집기+미리보기. 스토어 심사 부담 최소화.
- iOS: HealthKit / Android: Health Connect. 심박은 웨어러블 필요 → "있으면 보너스".

## 프로토타입 계획

### 검증하려는 것 (우선순위 순)

1. **"일하며 곁눈질하는 식당"이 실제로 기분 좋은가?** (방치+개입의 리듬)
2. "상황이 새겨진 재료 → 요리" 루프가 수집욕을 자극하는가?
3. 재료를 얻기 위해 현실 행동이 바뀌는가? (동기부여 루프)

### 단계

| 단계 | 내용 | 데이터 |
|---|---|---|
| **P1** | Godot 데스크탑 단독. 식당 1개, 재료 ~10종, 레시피 ~8종, 손님 ~5종, 두 속도 주방 | **목업** (디버그 패널로 재료 주입) |
| P2 | 폰 수집기 (걸음만) + 최소 동기화 | 실데이터 (걸음) |
| P3 | 날씨·시간대 맥락, 단골 스토리, 창 모드(위젯화), Steam 준비 | 확장 |

### P1 스코프 (이번 프로토)

- 창 하나 (추후 초경량 위젯화 전제, 지금은 일반 창)
- 식당 씬: 주방 + 테이블 2~3개, 손님 자동 방문
- 자동 파이프라인: 재료 → 손질 → 조리 → 서빙 → 돈
- 클릭 인터랙션 3종: 설거지 / 손질 / 서빙 돕기
- 업그레이드 3~5개 (자동화 속도)
- 디버그 패널: "오늘 5,000보 걸음 (비)" 같은 목업 재료 주입
- 저장/불러오기 (오프라인 경과 포함)

## 기술 메모

- **Godot 4.x** / 데스크탑 (macOS 우선, Steam 타깃이므로 Windows 병행)
- 상시 실행 전제 → CPU/배터리 초경량 목표 (P3에서 본격 대응)
- 개발 워크플로우: 클라우드(Claude Code 웹) + 맥북 로컬, GitHub로 동기화
- 동기화 서버(P2): 최소한의 저장소 (계정 → 재료 은행). 프로토는 무서버로 시작

## 세계관 후보 (미확정 — 3안 검토 중)

핵심 질문: **"왜 내 하루가 이 식당의 재료가 되는가?"** — 데이터 연동에 서사적 이유를 붙인다.

### 안 1. 🚪 경계의 식당
현실과 이세계 사이의 틈에 있는 식당. 한 명의 인간(플레이어)과 맺은 계약으로 운영되며,
그 사람이 살아가는 하루의 "맛"이 틈을 타고 흘러들어와 재료가 된다.
- 손님: 두 세계를 오가는 존재들. 이승을 그리워하는 것들, 저쪽에서 지친 것들
- 주제문 후보: **"내 평범한 하루가 누군가에겐 진귀한 맛이다"** (어느 안에든 이식 가능)
- 도우미 후보: 계약을 관리하는 작은 문지기 정령

### 안 2. 🌙 꿈결 식당
꿈의 가장자리에 있는 식당. 잠들지 못하는 존재들(꿈 잃은 도깨비, 불면의 달토끼)이
한 그릇 먹고 겨우 잠들러 온다. 플레이어의 깨어있는 활기가 그들에겐 잠을 부르는 자양분.
- 정서: 위로, 자장가. "당신이 열심히 산 하루가 누군가를 재워요"
- 도우미 후보: 졸린 눈의 견습 몽마
- 리스크: 밤 감성으로 톤이 좁음 — 낮에 켜두는 게임과 어긋날 수 있음

### 안 3. 🍂 환승역 식당 (현재 추천안)
정령·신·요괴·계절도 "이동"한다 — 겨울은 남쪽으로, 낡은 신은 은퇴하러. 그 길목의
환승역 식당. **이 식당의 화덕은 "인간의 이동"을 연료로 탄다** — 걷는 사람이 있어야 불이 붙는다.
- 손님: 매번 새 얼굴(여행자) + 계절마다 돌아오는 단골 → 콘텐츠 확장이 가장 자연스러움
- 정서: 여정, 계절감, 만남과 배웅. "잘 먹었어요, 또 지나갈게요"
- 도우미 후보: 역무원 겸 홀서빙을 보는 낡은 역귀(驛鬼)
- 추천 이유: "걸음 = 화덕의 연료"가 시스템과 서사를 가장 단단하게 접착

### 아트 방향 메모
- 프로토 단계: 플레이스홀더 그래픽(단순 도형/무료 에셋)으로 재미 검증 우선
- 검증 후: 커미션(외주)으로 본 아트 제작. 의뢰서 작성에는 세계관 확정이 선행 필요
